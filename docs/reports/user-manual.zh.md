# ManiScope 用户手册

## ManiScope 是什么

ManiScope 是一个用于分析 Solana memecoin 价格操纵行为的四面板可视化分析仪表板。它会加载预先计算好的数据集，包括 OHLC 行情、余额快照、链上转账记录和用户行为序列，针对 ACT 或 PNUT 两种代币之一运行实体聚类与操纵检测算法，再通过四个相互联动的可视化面板把结果呈现出来。

ManiScope 的定位是面向回溯调查的分析工具，而不是实时风控告警系统。它擅长回答“过去几周是谁在操纵这枚币、用的是什么手法”这类问题，而不是“此刻是否有可疑情况正在发生”。预期的使用方式是探索式的：先选定一个时间快照，运行检测算法，观察整体可视模式，发现异常时再点击单个钱包深入下钻。

## 屏幕布局

仪表板会铺满整个浏览器窗口，分成左中右三列。左列是一条窄长的控制面板。中列上下分割为两块，上方是代币持有者网络图，下方是行为时间线。右列是一张蜡烛图，上下分别夹着两行操纵事件卡片。

```
+----------------------------------------------------------------------+
|  ManiScope                                              o ACT  o PNUT |
+--------------+----------------------------+--------------------------+
|              | TokenDistribution          | CandlestickChart         |
|              | (持币者气泡网络图)          | -- 来回交易卡片行 ----    |
|              |                            | |   K 线 + 联动连接带 |  |
|  控制面板     |                            | -- 同向交易卡片行 ----    |
|              +----------------------------+                          |
|              | BehaviorDetails            |                          |
|              | (选中用户的多钱包时间线)    |                          |
+--------------+----------------------------+--------------------------+
```

## 四个面板的细节

### 1. 控制面板（左列）

控制面板是整个仪表板的驱动入口，从上到下依次分为三个区块，每个区块都有自己的执行按钮。

**Snapshot Configuration（快照配置）** 位于最上方。Snapshot Time 下拉菜单允许从 2024-10-19 12:00 UTC 起的任意整点中选取一个时间。仪表板里其他面板的所有结果都是相对于这个时间点计算出来的，因此切换它是你能做的影响最大的操作。两个阈值决定了最终落在屏幕上的钱包群体：Top Holders Threshold 默认为 0.3，意思是“能够覆盖累计 30% 用户余额的最小持币者集合”，数值越低则保留越少的更大持有者；Related User Threshold 默认为 0.2，用来挑选那些虽然不属于头部持有者但通过转账与之相连的二度钱包，把它们纳入“相关用户”范围。Update Snapshot 按钮会按当前选择的时间重新拉取数据并刷新网络图。

**Entity Detection（实体检测）** 在第二个区块。橙色的 Run Detection 按钮会触发钱包聚类算法。可以启用两类规则：Network Based 规则基于转账图，提供 Direct Transfer、Funding Relationship、Same Sender、Same Recipient 等开关，以及最小交易笔数和最小转账金额阈值；Similarity Based 规则基于行为相似度，包括钱包之间的余额相关性、收益相关性和交易序列相关性。Similarity Based 规则通常威力更大，因为两个看似独立的钱包却保持完美的余额相关，这本身就是共同所有者的强烈信号。

**Manipulation Detection（操纵检测）** 是第三个区块。它的 Run Detection 按钮会触发交易模式检测器。Round Trip 规则用于发现单钱包对敲洗盘，其参数包括买卖之间的最大时间间隔、允许的最大持仓差，以及最大已实现盈利。Same Direction 规则在面板的更下方，用于发现多钱包同向连续买入或卖出形成的协同行为。

有一个细节在 UI 上看不出来：页面首次加载时会自动运行两套检测算法，切换快照时间并点击 Update Snapshot 也会自动重跑。但是切换 ACT 与 PNUT 时操纵检测结果会被清空，必须手动再点一次 Run Detection 才能重新填充数据。

### 2. TokenDistribution（中列上方的气泡网络图）

TokenDistribution 用力导向布局渲染所选时间快照下头部持币者构成的网络图。它的标题栏会显示当前快照时间、一个 Scale 缩放滑块，以及当前活跃用户数。

可视化的解读依赖一组固定的视觉编码。气泡大小代表该钱包在快照时刻的持币余额，圆圈越大表示持有量越多。气泡填充使用蓝色渐变，颜色越深表示余额越高。圆圈边框是最重要的通道：蓝色边框表示该钱包当前没有被任何操纵事件标记，红色边框表示该钱包至少出现在一次被检出的操纵事件中。围在小群气泡外面的橙色虚线圆圈代表一个被实体检测器聚出来的实体，圈内的钱包被算法判定为属于同一个实体。主簇外围那些细小的浅色圆圈通过淡灰色细线连回主簇，它们就是“相关用户”，也就是本身不在头部持有者集合内、但与头部持有者之间存在转账关系的二度钱包。

这个面板上的交互很简单。点击任意气泡会选中对应的钱包，自动填充下方的 BehaviorDetails 面板，并在图中高亮该钱包所属的实体（如果它属于某个实体）。拖动标题栏里的 Scale 滑块可以整体放大或缩小图像。

每次进入这个面板时第一眼应该看的，是红色与蓝色边框的比例。少数红色是任何活跃代币的正常状态。绝大多数都是红色则意味着头部持有者中存在大面积的操纵活动，这就是开始深入调查的信号。

### 3. BehaviorDetails（中列下方的多行时间线）

BehaviorDetails 默认是空的，只有当你在上方的气泡图中点击了某个节点之后才会被填充。一旦激活，它会以堆叠时间线的形式展示出与当前选中用户相关的所有钱包，包括用户本人、用户所在实体的其他成员，以及通过转账与该实体相连的所有相关用户。

面板的每一行对应一个钱包，行首的标签由三字符的地址前缀加上角色标签组成，角色标签可能是 Selected User、Entity Member 或 Related User。横轴是时间，刻度形如 Mon 21、Wed 23 等等。每行上的小点代表该钱包的一笔交易动作，按动作类型用不同颜色编码，使买入、卖出和转账可以一眼分辨。面板顶部的 Show Manipulation Boxes 复选框开启后，会在每个钱包对应的操纵窗口处叠加一个彩色矩形覆盖层。

把多个钱包的时间线堆叠在一起的核心目的是“可视化协同检测”。如果两个钱包由同一个人操控，它们的小点会在垂直方向上对齐，因为它们在同一时刻执行了同一动作；如果两个钱包真的彼此独立，它们的小点会在各行之间随机散布。当多个钱包同时下场操纵时，会形成一道纵向贯穿大多数行的密集小点带，这是发现协同行为最直观的方式。

BehaviorDetails 中最被低估的功能是 Related User 行。实体检测器只在余额几乎完全同步时才会把钱包聚到一起，因此那些虽然由同一操纵者控制、但充提币时间表略有差异的钱包会被漏掉。Related User 行通过转账图把这些被漏掉的钱包重新拉回来，常常能揭示出比实体边框暗示的范围大得多的网络。

### 4. CandlestickChart（右列的 K 线与操纵事件卡片）

CandlestickChart 是一个三段式纵向布局。最上方是一行 Round-Trip 操纵事件卡片，中间是主 K 线图，最下方是另一行 Same-Direction 操纵事件卡片。当卡片数量超过宽度时，两行卡片都支持横向滚动。

每张 Round-Trip 卡片代表单个钱包的一次对敲洗盘事件。卡片上展示这次事件落入的小时槽位（比如 10/26 02:00）、精确的时间区间、对敲总美元金额、截断的钱包地址，以及一张迷你时间线，用彩色小点显示这一序列里买入和卖出的发生顺序。Same-Direction 卡片的形态相同，但代表的是多笔同向连续买入或卖出形成的爆发，而不是一次完整的对敲。在默认的 ACT 快照中，Round-Trip 卡片大约 7 张，Same-Direction 卡片大约 70 张。

主 K 线是一张标准的 OHLC 蜡烛图。绿色蜡烛代表收盘价高于开盘价（看涨），红色蜡烛代表收盘价低于开盘价（看跌）。右上角的颗粒度按钮可以在 1H、1D、3D、1W 之间切换 K 线柱子的时间粒度。

一个细微但很有用的覆盖层把上下两行卡片与 K 线图联动起来。每张卡片向下（或向上）延伸一条淡蓝色的连接带，落到 K 线图中对应的时间区域上。沿着竖直方向扫视即可看出某张操纵卡片对应的是哪一根蜡烛，这是把被标记的事件与价格响应对应起来最高效的方式。

### 代币选择器

页面右上角有一对小型单选按钮，标签分别是 ACT 和 PNUT。在两者之间切换会更换整个仪表板的数据源。ACT 在默认快照下大约有 51 个活跃头部持有者，7 张 Round-Trip 卡片和 70 张 Same-Direction 卡片。PNUT 在默认快照下大约有 191 个活跃头部持有者，整个网络图明显更密。需要注意的是，切换代币会清空操纵检测结果，必须再次点击两个 Run Detection 按钮才能重新填充。

## 推荐工作流

使用 ManiScope 最高效的方式是遵循下面这个十步节奏。

1. 选一个有意思的时间快照。通常选取一段价格波动结束附近的时间最为有用，因为这样可以看到行情高潮时刻每个钱包的实际持仓状态。
2. 把 Top Holders Threshold 调整到能够覆盖你关心的人群规模。默认的 0.3 是一个不错的起点。
3. 点击 Update Snapshot，等待几秒钟让网络图渲染完毕。
4. 依次点击 Entity Detection 和 Manipulation Detection 区块下方的橙色 Run Detection 按钮，运行两套检测算法。
5. 在 TokenDistribution 网络图上做一次整体扫视，估计红蓝边框的比例，并留意橙色虚线圆圈所标出的实体在哪里。
6. 点击图中最大的红色边框气泡。这通常对应着操纵量最大的钱包，从它入手能拿到最丰富的 BehaviorDetails 视图。
7. 在 BehaviorDetails 面板顶部勾选 Show Manipulation Boxes 复选框，让操纵窗口叠加显示在动作小点之上。
8. 寻找 BehaviorDetails 时间线上的纵向对齐。如果多行钱包的小点都集中在同一时间段里，那么这些钱包之间存在协同行为。
9. 把这些时间窗口与右侧的 K 线对照起来，沿着卡片下方的淡蓝色连接带找到对应的蜡烛，问一句：价格对这次协同爆发是怎么响应的？是被拉升、被砸盘、还是只是被维持？
10. 把 K 线图上下的操纵事件卡片当作“跳转到有趣时刻”的快捷方式。每张卡片都是一次预先发现好的事件，可以直接拿去与价格图核对。

## UI 上看不出来的几点注意事项

ManiScope 有几个不那么直观的特性，最好提前知道。

页面在首次加载时会自动针对默认快照获取操纵检测结果，因此进入页面后可以立即使用，不需要先点任何按钮。但切换代币会清空缓存的操纵结果，每次切换之后必须再次运行两套检测算法。

实体检测器默认存在“欠聚类”问题。它依赖按小时粒度的余额相关性，因此那些由同一个操纵者控制、但充提币时间表不一致的钱包不会被聚到一起。补救方式是：在运行实体检测之后，主动点击任意一个被标记的成员节点，去阅读 BehaviorDetails 中的 Related User 行。剩下那部分网络通常会从这些行里浮现出来。

Same Direction 检测同时包含单钱包的快速连续动作，并不仅仅是多钱包协同砸盘。一个钱包在 60 秒内连续买入 5 笔金额几乎相同的订单，与三个不同钱包在同一窗口内集体砸盘，会在底部卡片行里产生形态相似的卡片。这意味着像机械臂般运作的算法交易和真正的协同操纵都会出现在底部卡片中，因此不要简单地把“70 张同向卡片”理解为“70 个独立的协同小组”。

K 线上的操纵连接带视觉上比较淡，画的是浅蓝色的渐变带。但它是把卡片与某个具体时间区域唯一联系起来的视觉元素，值得花点时间训练眼睛去跟随它。

时间快照的选择比想象中更重要。在价格高点选取的快照与在缓慢下行阶段选取的快照得到的头部持有者群体并不相同，因为有些钱包在两个时间点之间退出了头部群体。如果想看清楚操纵高峰前后谁进谁出，就尝试几个不同的快照时间并加以对比。

最后，仪表板目前没有展示钱包标签。底层数据中的 `simplified_owner_labels.json` 文件可以区分交易所钱包、合约钱包和普通用户钱包，但这些标签尚未在 UI 中暴露。能否区分某个“头部持有者”实际上是中心化交易所的充值地址，会显著改变对许多被标记事件的解读，因此把钱包标签接入 UI 是值得列为后续改进项的事情。
